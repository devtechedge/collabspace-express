# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| latest `main` | ✅ Yes |
| older branches | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public GitHub issue.**

Instead, report it privately:

1. Go to the [Security tab](https://github.com/devtechedge/collabspace-express/security/advisories/new) on this repository
2. Click **"New draft security advisory"**
3. Describe the vulnerability, steps to reproduce, and potential impact

We will acknowledge your report within **48 hours** and aim to release a fix within **7 days** for critical issues.

Thank you for helping keep CollabSpace secure.
